# 2.1 — Module 2 (DPNDA): NDA Templates and Fields

> **2026-07-02:** Reconciled against `reqs/DPO EFORM 2 SAMPLE.pdf` and
> `reqs/DPO EFORM 5 SAMPLE.pdf` — two EVP-approved forms revealing that "DPNDA" actually covers
> **two distinct NDA instruments** under two different DPO policies, not one. The original
> version of this file modeled only the OJT/trainee case. See `CHANGELOG.md` and
> `0.4-dpo-ethics-integration.md`.

## Purpose
Electronic submission and signing of Non-Disclosure Agreements. Two instrument types:

| Instrument | Policy | Signed by | Trigger |
|---|---|---|---|
| **Research Team NDA** (Form 2) | DPO-POL-005 | Researcher/team lead + every co-researcher | Part of the same submission as Form 1 (`1.1`) — required before a joint clearance (Form 3) can be released |
| **OJT/Trainee NDA** (Form 5) | DPO-POL-002 | Trainee + Department Head | Independent of research applications — tied to an OJT/trainee/community-service **placement** |

---

## 2.1.a — Research Team NDA (Form 2, DPO-POL-005)

### Fields (source: Form 1, confirmed)
| Field | Type | Required | Notes |
|---|---|---|---|
| Research Title | Text | Yes | Same value as the linked Form 1 application |
| Researcher or Team Lead | Text | Yes | |
| Total Number per Group | Number | Yes | Matches Form 1's "How many are doing the research" |
| Adviser's Name | Text | Yes | |
| Department / Level / Course / Section | Text (4 sub-fields) | Yes | |
| Respondents | Text | Yes | |
| Total Respondents | Number | Yes | |
| Data Collection Method | Text | Yes | |
| Data Capturing Tool | Text | Yes | |
| Research Duration | Date range | Yes | Start / End |

### Obligations Checklist (source: Form 2, confirmed — Yes/No/Not Applicable per item)
1. Data used solely for the study's purpose
2. No disclosure/publication/dissemination of confidential information to third parties without
   prior written school consent
3. No commercial, personal, or other unauthorized use of the information
4. Participants' identities and responses anonymized and kept confidential
5. Reasonable security measures maintained (e.g., password-protected files)
6. Avoid exposing participants to harm or risk
7. Return or destroy all confidential information/copies at the school's request upon completion
8. Promptly share a PDF copy of the completed study via the EDMS, if requested

### Signatories (source: Form 2, confirmed)
| Field | Type | Required | Notes |
|---|---|---|---|
| Data Privacy Policy certification checkbox | Checkbox | Yes | |
| Per-member: Name, Role, Signature | Repeatable row | Yes, one per team member | Role = Leader / Member |

### Output
System generates a signed NDA PDF combining the template, filled fields, and each member's
signature. This NDA must be fully executed (all team members signed) before the research
application's DPO track (`1.2`) can reach `Approved`.

## 2.1.b — OJT/Trainee NDA (Form 5, DPO-POL-002)

> Replaces the prior paper "NDA-4" process. This instrument is what the rest of `2.x`
> (workflow, `2.2`) and `4.2`'s repository structure originally modeled as "DPNDA."

### Fields (source: Form 5, confirmed)
| Field | Type | Required | Notes |
|---|---|---|---|
| Trainee Full Name | Text (Last, First, M.I.) | Yes | |
| Gender | Dropdown | Yes | |
| Age | Number | Yes | |
| Enrolled In School | Text | Yes | |
| Number of Hours Needed | Number | Yes | |
| Department / Level / Course / Section | Text (4 sub-fields) | Yes | |
| Address | Text (House No. / Street / Barangay / City) | Yes | |
| Department Assigned | Dropdown | Yes | Host department accepting the trainee |
| PCC Supervisor/Coordinator | Text | Yes | |
| Endorsed By | Text | Yes | |
| Duration Date | Date range | Yes | Start / End |

### Obligations Checklist (source: Form 5, confirmed — Yes/No/Not Applicable per item)
1. Adherence to Data Privacy Policies — compliance with data privacy laws and school policy
2. Maintain Strict Confidentiality — no disclosure without prior written consent
3. No Recording — no audio/video/photo recordings without explicit prior written permission
   (and parent/guardian consent where applicable)
4. No Identification — no identifying any student by name/PII in notes, discussions,
   assignments, or reports, unless explicitly anonymized or approved
5. Proper Handling of Information — secure storage and disposal of confidential materials at
   end of placement or as instructed
6. Reporting Breaches — immediate notification of any actual/suspected breach
7. Adherence to School Policies — code of conduct, visitor policies, other guidelines

### Terms and Signatories (source: Form 5, confirmed)
| Field | Type | Required | Notes |
|---|---|---|---|
| Effective/duration acknowledgment checkbox | Checkbox | Yes | |
| Termination-notice acknowledgment checkbox (5 days' written notice) | Checkbox | Yes | |
| Trainee E-Signature | Signature capture | Yes | |
| Department Head E-Signature | Signature capture | Yes | Countersignature |

### Output
System generates a signed NDA PDF combining the template, filled fields, and captured
signatures, auto-named per `4.2-file-management-naming.md`.

## NDA Template Management (ASSUMPTION, unchanged from prior draft)
- DPO/Admin can upload and manage multiple NDA template versions per department, for either
  instrument type.
- Each signed NDA record stores which template version was used, for audit purposes.
