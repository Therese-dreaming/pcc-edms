## File Naming Convention
See shared convention in `4.2-file-management-naming.md`. DPREQ-specific pattern:

```
DPREQ_[ApplicationID]_[DocumentType]_[YYYYMMDD].[ext]
Example: DPREQ_2026-000045_ResearchProposal_20260702.pdf
```

## Repository Placement
All DPREQ documents are stored under:
```
/Repository/DPO/DPREQ/[Year]/[ApplicationID]/
```

## Retention (ASSUMPTION — confirm actual DPO retention policy)
- Active applications: retained indefinitely while application is open
- Approved/Issued clearances: retained per institutional records retention schedule (confirm years)
- Rejected applications: retained for a minimum audit period (confirm duration)
