# 5.3 — Reports: DPO-Specific

> **Data model note:** Several reports below require structured **placement/assignment data**
> (school, department, grade level, internal/external status, date range) that goes beyond a
> single signed NDA file. Recommend a dedicated `Placement` record (linked 1:1 or 1:many to a
> DPNDA record) with these fields, rather than deriving everything from the NDA document itself.
> See `2.1-dpnda-nda-template.md` for current proposed fields — extend as needed.

## Report: Number of accomplished NDAs per department and per grade level
- Source: DPNDA records with status = Completed/Archived
- Grouping: Host Department × Grade Level
- Filters: date range
- Output: cross-tab table; export Excel

## Report: Pending DPO approvals, with reasons and comments
- Source: DPREQ (and DPNDA if DPO countersignature required) records with status = Under
  Review / Returned / Endorsed (i.e., not yet finalized)
- Fields shown: Applicant, submission date, current status, reviewer comments/reasons, days pending
- Filters: date range, status, department
- Output: table; export PDF/Excel

## Report: Number of student teachers observing classes per grade level, department, and school (external and internal)
- Source: DPNDA/Placement records where Trainee Type = Student Teacher
- Grouping: Grade Level × Department × School × Internal/External
- Filters: date range
- Output: cross-tab table; export Excel

## Report: Number of external and internal OJTs accommodated per month and per year, per school and per department/office
- Source: DPNDA/Placement records where Trainee Type = OJT
- Grouping: Month/Year × School × Department/Office × Internal/External
- Filters: date range (month or year granularity)
- Output: table + trend chart; export Excel

## Report: Number of OJTs/student teachers' whereabouts at a given time
- Source: DPNDA/Placement records — Placement Start Date, Placement End Date, Host Department
- Logic: "active" = selected date falls between start and end date
- Filters: specific date (or date range), department
- Output: table listing trainee, department, status (on-site expected) as of the selected date
- **Open question:** does "whereabouts" require real-time location/attendance check-in, or is a
  placement-schedule snapshot sufficient? (Source doc implies the latter; confirm with DPO.)

## Report: Offices and departments that have uploaded OJT evaluation reports, and those without
- Source: OJT Evaluation Report upload record (ASSUMPTION — new document type, linked to
  Placement record, uploaded by Dept Coordinator at end of placement)
- Grouping: Department/Office
- Metrics: Uploaded vs. Not Uploaded, by department
- Filters: date range (placement period), department
- Output: table, two lists (compliant / non-compliant departments); export PDF/Excel

> **Gap flagged:** "OJT evaluation report" is not defined elsewhere in the source requirements
> as a form/document type. Recommend adding it as an explicit deliverable in `2.1` (Dept
> Coordinator uploads evaluation report at placement end) so this report has a real data source.
