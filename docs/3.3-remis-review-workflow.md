## Status Lifecycle

```
Draft Submitted → Under Endorsement (Adviser → Program Head → Dean) → For Screening →
   For Review (per risk track) → Approved / Approved with Conditions / Deferred →
   Clearance Issued → Monitoring → Closed → Archived
        |                              |
        v                              v
   For Revision (returned by any      Disapproved
   endorser, secretariat, or
   reviewer) → resubmit
```

| Status (FRS §V, confirmed) | Description | Actor who moves it |
|---|---|---|
| Draft Submitted | Researcher preparing/submitting application | Researcher |
| Under Endorsement | Sequential academic endorsement: Adviser → Program Head → Dean (FRS §IV) | Adviser → Program Head → Dean |
| For Screening | Administrative completeness check | Ethics Secretariat |
| For Revision | Returned with comments — from endorsement, screening, or review stage | Any endorser / Secretariat / Ethics Reviewer → Researcher |
| For Review | Substantive ethics review (track per risk classification, `3.2`) | Ethics Reviewer(s) |
| Approved | Committee approves without conditions | Ethics Committee Chair |
| Approved with Conditions | Approved contingent on stated conditions | Ethics Committee Chair |
| Deferred | Decision postponed pending additional information | Ethics Committee Chair |
| Disapproved | Application denied, with reason | Ethics Committee Chair |
| Clearance Issued | This track's signature applied to the joint certificate (with QR code, see `3.1`); **released to applicant only once DPO's track also signs**, see `0.4-dpo-ethics-integration.md` | System (auto, on second signature) |
| Monitoring | Study in progress, subject to periodic monitoring (`3.4`) | Ethics Reviewer |
| Closed | Study concluded per Completion Module (`3.4`) | Ethics Secretariat / System |
| Archived | Closed record moved to read-only archive | System (auto) |

## Endorsement Procedure (FRS §IV, confirmed)
1. Researcher submits application → status `Draft Submitted`.
2. Routed sequentially: **Adviser → Program Head → Dean/Academic Head**.
3. At each step, the endorser may: **Approve** (forward to next endorser), **Return with
   Comments** (status → `For Revision`, back to Researcher), or **Reject** (status →
   `Disapproved`, application ends here).
4. Each endorsement action records: name of endorser, date/time, remarks, e-signature
   (FRS §IV, confirmed).
5. On Dean approval, application routes to Ethics Secretariat → status `For Screening` (`3.2`).
6. After screening passes, Ethics Secretariat assigns the tracking number
   (format `REC-YYYY-NNNN`, FRS §V) if not already assigned, and routes to risk classification
   → substantive review (`3.2`).
7. Ethics Reviewer(s) complete review, submit recommendation (Approve / Minor Revision / Major
   Revision / Disapprove — FRS §VIII).
8. Ethics Committee Chair consolidates reviewer recommendations and issues the final decision
   (Approved / Approved with Conditions / Deferred / Disapproved — FRS §X), recording Decision
   Date, Conditions, Remarks, Authorized Signatories.

## Reviewer Assignment
- Ethics Reviewers are assigned per application by the Ethics Committee Chair, based on risk
  track and current workload (FRS §VIII: "Assigned Applications" on Reviewer Dashboard).
- Reviewer workload (count of active assigned applications) feeds the
  **"Reviewer Workload"** report (`5.2-reports-ord.md`).

## Notifications
- Submission received → Researcher + Adviser
- Endorsement step advanced → Researcher + next endorser
- For Revision (from any stage) → Researcher
- Routed to Ethics Secretariat → Ethics Secretariat
- Routed to Ethics Reviewer(s) → Ethics Reviewer(s)
- Decision issued (any of the four outcomes) → Researcher
- Clearance Issued → Researcher
- Monitoring milestone due → Researcher + Ethics Reviewer
