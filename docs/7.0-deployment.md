## Build for Portability (so deployment isn't blocked later)
- All environment-specific values (DB credentials, mail server, storage driver, app URL/domain,
  signing keys) must live in `.env` — never hardcoded — per Laravel convention.
- File storage must be abstracted via Laravel's Filesystem so it can point to local disk now and
  S3-compatible storage later without code changes (see `8.0-tech-stack.md`).
- Avoid hardcoding the domain anywhere in frontend or backend code; use `APP_URL` / relative
  routing.
