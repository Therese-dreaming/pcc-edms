# 0.3 — Glossary

> **2026-07-02:** Added terms introduced by the REMIS FRS alignment pass (`CHANGELOG.md`):
> Ethics Secretariat, Ethics Reviewer, Ethics Committee Chair, Academic Endorsement Chain,
> Tracking Number, Verification Portal, Incident.

| Term | Definition |
|---|---|
| DPO | Data Privacy Office |
| ORD | Office of Research and Development |
| REC | Research Ethics Committee (under ORD) |
| DPREQ | Module 1 — Data Privacy Requirements clearance application |
| DPNDA | Module 2 — Data Privacy NDA e-signing for OJTs/trainees |
| REMIS | Module 3 — Research Ethics Management Information System |
| OJT | On-the-job trainee |
| NDA | Non-Disclosure Agreement |
| Clearance | Formal approval document issued by DPO or REC authorizing research/data activity to proceed |
| Endorsement | An intermediate approval step where a reviewer forwards an application to the next approver |
| Academic Endorsement Chain | REMIS-specific sequential endorsement of Researcher → Adviser → Program Head → Dean/Academic Head, required before administrative screening (FRS §IV) |
| Ethics Secretariat | REMIS role that receives applications, conducts administrative screening, assigns tracking numbers (FRS §II) |
| Ethics Reviewer | REMIS role that performs substantive ethics review and risk classification, submits recommendations (FRS §II) |
| Ethics Committee Chair | REMIS role that assigns reviewers, consolidates reviews, and issues the final decision (FRS §II) |
| Risk Classification | REMIS category (Minimal / Moderate / High Risk) assigned during screening, determining review track (Expedited/Committee/Full Board) |
| Tracking Number | System-generated unique record ID, format `[MODULE]-YYYY-NNNN` (e.g. `REC-2026-0001`), see `4.2-file-management-naming.md` |
| Verification Portal | Public, read-only page where a clearance certificate's authenticity/validity can be checked by tracking number or QR scan, without login |
| Incident | A reportable event during an active/monitored REMIS study — Participant Complaint, Data Breach, Confidentiality Breach, Psychological Harm, Protocol Violation, or Other — tracked via `3.5-remis-incident-reporting.md` |
| Audit Trail | Chronological, immutable log of user actions on a record |
| Repository | Centralized, searchable digital document storage shared across modules |
