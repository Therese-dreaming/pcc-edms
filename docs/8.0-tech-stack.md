# 8.0 — Tech Stack

## Confirmed Stack
| Layer | Technology |
|---|---|
| Frontend | React |
| Backend | Laravel (PHP) |

## Proposed Supporting Stack (ASSUMPTION — confirm each before build)

### Frontend
| Concern | Proposed Choice | Notes |
|---|---|---|
| Frontend/Backend integration | Inertia.js, **or** separate React SPA + Laravel REST API | Inertia = simpler (no separate API layer, shared routing/auth); separate SPA = more flexible for future mobile app. **Needs a decision.** |
| Styling | Tailwind CSS | Pairs well with Laravel's default tooling |
| State management | React Query (if separate SPA) or Inertia's built-in page props | Depends on integration choice above |
| Form handling | React Hook Form + Zod (or Laravel Precognition if using Inertia) | For client-side validation matching server rules |
| E-signature capture | `signature_pad` (canvas-based) or similar React signature component | See `4.3-esignature-notifications.md` |
| Build tool | Vite (Laravel's default) | |

### Backend
| Concern | Proposed Choice | Notes |
|---|---|---|
| Framework | Laravel (latest LTS) | |
| API style | REST (JSON), or Inertia responses if using Inertia | |
| Authentication | Laravel Sanctum (SPA/token auth) or Laravel Breeze/Fortify if using Inertia | Confirm SSO requirement — does PCC have an existing institutional login (e.g., Google Workspace/Microsoft 365) to integrate with? |
| Authorization | Laravel Policies + Gates, mapped to role matrix in `0.2-stakeholders-and-roles.md` | |
| Queue/Jobs | Laravel Queues (database or Redis driver) | For notification sending, PDF generation, report generation |
| PDF generation | `barryvdh/laravel-dompdf` or `spatie/laravel-pdf` | For clearance certificates, signed NDAs, reports |
| File storage | Laravel Filesystem (local disk in dev; S3-compatible object storage in production) | See `4.2-file-management-naming.md` |
| Audit logging | `spatie/laravel-activitylog` or custom audit table | See `4.4-audit-trail-status-tracking.md` |

### Database
| Concern | Proposed Choice | Notes |
|---|---|---|
| RDBMS | **MySQL 8.0+** (confirmed, `architecture.md` ADR-003) | Chosen for hosting compatibility; MySQL 8.0+ supports JSON columns and window functions needed for `5.x` reporting |
| Migrations/Seeding | Laravel Migrations + Seeders | Standard Laravel workflow |

### Testing
| Concern | Proposed Choice |
|---|---|
| Backend | Pest or PHPUnit |
| Frontend | Vitest + React Testing Library |
