# 4.4 — Audit Trail and Status Tracking

## Audit Trail — Logged Events (minimum set)
| Event | Data Captured |
|---|---|
| Record created | User, timestamp, record ID |
| Record submitted | User, timestamp |
| Status change (any) | Old status, new status, user, timestamp, comments (if any) |
| Document uploaded/replaced | User, timestamp, filename, version |
| Signature applied | Signer, role, timestamp, IP/device |
| User role changed | Admin, target user, old role, new role, timestamp |
| Record accessed/viewed (sensitive records only — ASSUMPTION, still open — confirm scope) | User, timestamp |
| Report generated | User, report type, filters used, timestamp |

## Audit Trail Report
- Filterable by: date range, module, user, record ID, event type
- Exportable (PDF/Excel)
- Read access restricted to Admin, **DPO Staff** (DPO Approver was retired as a separate role,
  2026-07-06), REC Chair — confirmed 2026-07-06, no longer an assumption

## Status of Application (applicant-facing)
- Applicants see a simplified progress tracker (not full internal audit detail):
  e.g., "Submitted → Under Review → Approved" with current step highlighted
- Internal reviewers see full status + all comments/history

## Tracking of Request
- Every record has a persistent, searchable Request/Application ID
- Applicants can search their own records by ID or title
- Reviewers/Admins can search across all records within their office scope
