# 0.2 — Stakeholders and User Roles

> **2026-07-02:** Role list rebuilt to match the authoritative
> `REMIS_Functional_Requirements_Specification.md` (FRS §II). The previous version collapsed
> REMIS's academic endorsement chain (Adviser → Program Head → Dean) and its Ethics
> Secretariat/Reviewer/Chair split into a single generic "REC Reviewer/REC Chair" pair — that
> undercounted five distinct roles with five distinct permission sets. See `CHANGELOG.md`.
>
> **2026-07-06:** DPO-side role list confirmed directly by DPO (was previously an unconfirmed
> assumption — no source FRS exists for DPREQ/DPNDA the way REMIS has one). Two changes from the
> assumption this replaces: **DPO Approver was retired** — DPO Staff is now the single DPO-side
> role, owning the DPO track end to end including final approval — and **Student Teacher was
> retired as a distinct role** — that population is tracked as ordinary internal/external OJT
> placements, not a separate category. See `CHANGELOG.md` for the code diff.

## Role List

### DPO-side roles (DPREQ, DPNDA — confirmed with DPO 2026-07-06)

| Role | Office | Description |
|---|---|---|
| Researcher (Internal) | Requester | PCC faculty/staff/institutional researcher submitting DPREQ applications |
| Researcher (External) | Requester | Non-PCC researcher submitting DPREQ applications |
| OJT / Trainee (Internal) | Requester | PCC student doing OJT within PCC (includes student teachers placed within PCC) |
| OJT / Trainee (External) | Requester | Non-PCC OJT placed within PCC (includes student teachers placed externally) |
| Department/Office Coordinator | Host unit | Coordinates OJT/community-service placement for a department; uploads OJT evaluation reports; countersigns NDAs |
| DPO Staff | DPO | Sole DPO-side role: reviews DPREQ applications and DPNDA submissions, screens, endorses, approves/rejects, and issues clearances end to end |

### REMIS-side roles (source: FRS §II — confirmed, not an assumption)

| Role | Description (per FRS) |
|---|---|
| Researcher (Student / Faculty / Academic Non-Teaching Personnel / Non-teaching Support Personnel) | Create application, upload documents, submit revisions, view status, download clearance |
| Adviser | Review proposal, endorse application, return application |
| Program Head | Review endorsement, approve endorsement |
| Dean / Academic Head | Final academic endorsement |
| Ethics Secretariat | Receive applications, conduct administrative screening, assign tracking numbers, generate reports |
| Ethics Reviewer | Access assigned applications, complete review forms, submit recommendations |
| Ethics Committee Chair | Assign reviewers, consolidate reviews, issue decisions |

### Shared roles

| Role | Office | Description |
|---|---|---|
| System Administrator | IT | User management, rights classification, system configuration — one role, spans both DPO and ORD/REC per FRS §II item 8 |
